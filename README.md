# Sistema de Consulta de CEP

Projeto desenvolvido em Python para consultar CEPs utilizando a API ViaCEP.

## Sobre o projeto

O programa permite que o usuário digite um CEP e receba informações sobre o endereço, como rua, bairro, município e estado.

## Funcionalidades

- Consulta de CEP.
- Verificação dos números digitados.
- Aceita CEP com hífen e pontos.
- Exibe as informações do endereço.
- Possui menu para consultar outro CEP ou sair.
- Tratamento de erros durante a consulta.

## Tecnologias utilizadas

- Python
- Biblioteca Requests
- API ViaCEP

## Como executar

1. Tenha o Python instalado.
2. Instale a biblioteca Requests:

   `pip install requests`

3. Execute o arquivo `leitordecep.py`.

## API utilizada

[ViaCEP](https://viacep.com.br/)

Projeto criado para praticar meus conhecimentos em Python e aprender a utilizar APIs.
